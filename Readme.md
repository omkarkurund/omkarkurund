### 🧠 DocuMind: Production-Grade RAG Knowledge Assistant
Grounded Q&A over private document collections.
- 50-question benchmark measuring **retrieval recall, precision, and grounding accuracy**; used it to find and fix a retrieval-quality issue and 3 production bugs before deployment
- **Hallucination-resistant grounding**: exposes similarity scores, retrieved chunk counts, and groundedness metrics instead of fake confidence numbers
- **Swappable architecture**: four-layer design, so any vector DB or LLM provider changes via a single adapter
